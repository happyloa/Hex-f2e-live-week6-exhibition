# 設計實作對照

以 Adobe XD 的 16 張桌機與手機畫板、Reference 頁和公開留言核對。 [Adobe XD 畫板](https://xd.adobe.com/view/057f9d4e-6781-43fe-9aea-9f73f67dd2fd-502c/grid/)

| 設計稿項目                           | 網站行為                                                                                             |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 桌機首頁分類的 Hover 留言            | 滑鼠移入及鍵盤焦點顯示底線。點選後開啟該分類列表，手機分類列可橫向捲動。                             |
| 桌機首頁推薦的 Swiper 留言           | 推薦展覽可拖曳、以鍵盤方向鍵或分頁圓點切換。手機依畫板直向排列。                                     |
| Reference 頁的圖示、字型與素材       | 使用 Google Material Icons、Roboto、Noto Sans TC 及課程圖片。                                        |
| 桌機與手機的展覽、購物車及結帳連線   | 首頁、分類、展覽詳情、購物車、四步結帳及返回連結皆有目的頁。                                         |
| 只有入口的帳戶、收藏、回顧與看展操作 | 增設登入、註冊、帳戶、收藏、文字回顧與線上展間。課程素材提供回顧圖片，網站以圖文說明呈現。           |
| 捲軸與選取文字                       | 頁面與分類使用酒紅色捲軸，購物車使用適合深色背景的配色。文字選取採酒紅底白字，高對比模式沿用系統色。 |
